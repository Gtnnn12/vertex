3. NETREX
--------------------------------------------------------------------------------
Funcionalidad: REAL - autoridad backend

Grant:
- POST /api/admin-center/users/:id/netrex
- Validación: staff rank, usuario no federado, sin rank violation
- Duraciones: 1h, 1d, 3d, 7d, 14d, 30d, 90d, custom, permanent
- Persiste: netrexEnabled=1, netrexExpiresAt en DB
- Audit log: netrex_grant event

Revoke:
- POST /api/admin-center/users/:id/netrex/revoke
- Quita: netrexEnabled=0, netrexExpiresAt=null
- Valida: usuario tiene grant activo
- Audit log: netrex_revoke event

Extend (nuevo):
- POST /api/admin-center/users/:id/netrex/extend
- Extiende duración desde expiry actual o ahora
- Mismo validación de ranks que grant
- Audit log: netrex_extend event

Estado del usuario:
- netrexEnabled: boolean (1/0)
- netrexExpiresAt: timestamp ms o null (permanent)
- netrexState: 'active' | 'permanent' | 'expired' | 'none'
- Cálculo server-side: authority definitiva

Frontend integration:
- NetrexSection.tsx muestra badges, features, pricing
- AdminNetrex.tsx gestiona grant/revoke/extend en admin
- StaffBadge muestra NETREX chip
- User profile muestra estado Netrex
- Active Now integra actividad Netrex user

5. MODERATION
--------------------------------------------------------------------------------
Estado: FUNCIONAL

Tipos: warn, timeout, ban
Soporta: temporal, permanente

Guardar: target (userId), actor (staffId), reason (string|null), createdAt (ms), expiresAt (ms|null), status

Acciones:
- warn: sin duración, solo evento de moderation
- timeout: duración en horas, forceDisconnectUser, establece bannedUntil
- ban: duración o PERMANENT_BAN_UNTIL, establece bannedUntil/banReason/bannedAt/bannedBy
- unban: quita bannedUntil, banReason, bannedAt, bannedBy

Historial permanente: moderationEvents table, never deleted on expire

Acciones admin API:
- POST /api/admin-center/users/:id/moderation
- Validación de rank: STAFF_BAN_MIN_RANK para timeout/ban/unban
- Propia-protección: cannot moderate own account
- Rank violation protection: cannot moderate staff at/above own rank

Audit log: cada acción escribe audit_log con actor, target, action, reason, metadata
